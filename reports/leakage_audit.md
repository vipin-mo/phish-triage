# Leakage audit

Generated by `python -m phish_triage.data.audit`. ROC AUC on the test part of the `random` split (13,258 train / 2,840 test emails). 0.5 means no signal; 1.0 means the features alone separate phishing from legitimate mail.

## Features that should not predict phishing

| Feature group | Raw AUC | Masked AUC | Strongest masked features (phishing / legitimate) |
|---|---:|---:|---|
| header names | 1.000 | 0.776 | `mime-version`, `from`, `importance`, `x-priority` / `to`, `user-agent`, `date`, `content-language` |
| header order | 1.000 | 0.787 | `content-transfer-encoding > x-priority`, `x-priority > importance`, `from > subject`, `subject > mime-version` / `content-transfer-encoding > user-agent`, `content-language > user-agent`, `x-mailer > user-agent`, `content-transfer-encoding > content-language` |
| recipient domain | 1.000 | 0.571 | `none`, `cc:example.com`, `to:example.com` / `to:example.com`, `cc:example.com`, `none` |
| Authentication-Results | 0.996 | 0.500 | `absent` / `absent` |
| Message-ID domain | 0.922 | 0.500 | `none` / `none` |
| date | 0.470 | 0.470 | `year:2017`, `month:01`, `year:2021`, `month:11` / `month:12`, `year:2015`, `year:2020`, `year:2019` |

# Leakage audit

Generated by `python -m phish_triage.data.audit`. ROC AUC on the test part of the `random` split (13,072 train / 2,802 test emails). 0.5 means no signal; 1.0 means the features alone separate phishing from legitimate mail.

## Domains and links (masked)

Links keep their real domains, so the legitimate source's own domain (`apache.org`) appears in 46.2% of the legitimate emails and 0.0% of the phishing ones.

| Check | AUC | Strongest features (phishing / legitimate) |
|---|---:|---|
| Link domains, as tokens (no model uses them this way) | 0.942 | `t.co`, `googleapis.com`, `run.app`, `sendgrid.net` / `apache.org`, `github.com`, `localhost`, `stackoverflow.com` |
| Link features the models use | 0.9732 | |
